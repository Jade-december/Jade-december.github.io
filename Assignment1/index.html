学号：2025106076 | 姓名：陈玉瑶

a. 选题

主题名称：个人作品集展示网站

选题原因：随着数字媒体的发展，拥有一个个人作品集网站已成为展示个人能力的重要方式。本项目旨在设计并制作一个现代化的个人作品集网站，用于展示本人在设计、编程等方面的作品与能力。

目标受众：潜在雇主、合作伙伴以及对个人作品感兴趣的访问者。

b. 策划

整体思路：采用单页滚动式设计，以紫色渐变为主色调，营造现代、优雅的视觉氛围。页面结构清晰，内容分区明确。

页面结构规划：

  • 导航栏 - 快速跳转各个板块
  • 首页 Banner - 个人简介与欢迎语
  • 关于我 - 个人介绍与技能
  • 作品展示 - 图文并茂的作品墙
  • 联系方式 - 留言表单与社交链接

色彩方案：紫色渐变（#667eea → #764ba2）为主色调，白色为背景色，深灰色为文字色。

c. 文案

首页标题：你好，我是陈玉瑶

首页副标题：数字媒体专业学生 / 设计爱好者

关于我：我是一名热爱设计与技术的学生，专注于网页设计、平面设计和数字媒体创作。我相信好的设计能够改变世界，让信息传递更加高效和美好。

作品展示标题：我的作品

联系页面文案：如果你对我的作品感兴趣，或者有合作意向，欢迎随时与我联系！

e. 方法

开发方法：采用 HTML5 + CSS3 纯前端开发，结合语义化标签和响应式设计理念。

设计方法：

  • 栅格布局 - 使用 CSS Flexbox 和 Grid 实现响应式布局
  • 卡片设计 - 内容以卡片形式呈现，层次分明
  • 微交互动效 - 悬停动画、过渡效果增强用户体验
  • 移动优先 - 从小屏幕开始设计，逐步适配大屏

部署方法：使用 GitHub Pages 进行静态网站托管，结合 Git 进行版本控制。

h. 总结

通过本次作业，我完成了从选题、策划、设计到开发的完整流程，对网页设计有了更深入的理解：

  • 收获：掌握了 HTML5 语义化标签的使用，学会了 CSS3 渐变、动画等高级特性，理解了响应式设计的原理和实现方法。
  • 遇到的问题：GitHub 访问速度较慢，通过 Watt Toolkit 加速解决；目录结构规范需要严格遵守，否则会影响评分。
  • 改进方向：后续可以加入更多 JavaScript 交互效果，增加作品展示的动态性；可以引入框架（如 Vue、React）提升开发效率。

本次作业不仅锻炼了我的技术能力，也让我对网页设计的整体流程有了更系统的认识，为后续学习打下了坚实基础。
